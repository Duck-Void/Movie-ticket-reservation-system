# Movie Ticket Reservation System

A simple Python-based Movie Ticket Reservation System that allows users to view available movies, book multiple tickets, and view their bookings.

## Features

- View available movies
- View ticket prices
- Book movie tickets
- Make multiple bookings
- View all previous bookings
- Calculate total ticket price
- Simple menu-driven interface
- Uses multiple Python modules
