# Movie Ticket Reservation System

## Problem Statement

Design and develop a simple, menu-driven Movie Ticket Reservation System using Python. The system should allow users to view available movies and their ticket prices, select a movie, enter the number of tickets, calculate the total booking amount, and store multiple bookings.

The program should use **at least three Python modules** to demonstrate modular programming. The system should provide a user-friendly menu that allows users to view movies, book tickets, view their existing bookings, and exit the program.

## Requirements

The system should provide the following functionalities:

1. Display a list of available movies with their ticket prices.
2. Allow the user to select a movie.
3. Allow the user to enter the number of tickets.
4. Calculate and display the total ticket price.
5. Store multiple bookings during a single session.
6. Display all existing bookings.
7. Handle invalid movie choices and invalid ticket quantities.
8. Provide an option to exit the program.
9. Divide the program into at least three separate Python modules.

## Modules

The project should contain the following modules:

- `main.py` – Controls the overall program and menu.
- `movies.py` – Stores movie information and displays available movies.
- `booking.py` – Handles ticket bookings and booking records.
- `display.py` – Displays the main menu.

## Objective

The objective of this project is to develop a basic movie reservation system while demonstrating fundamental Python programming concepts and the use of modular programming.
